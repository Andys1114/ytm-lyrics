# 歌词工具：选词、同步与设置

歌词标题栏左侧是 **歌词 / 选词 / 设置**，偏移胶囊在右侧、紧靠原生关闭按钮。选词、设置和清除确认使用同高的离线 MDUI 面板（屏幕高度的 90%）；偏移滚轮以胶囊为中心上下展开，不增加一行。

## 选对歌曲版本

“选词”把各来源的可同步候选放在一张列表里，匹配度最高的排在前面。每项显示歌名、歌手、专辑、时长、来源和逐字／逐行／译文状态；正在使用的版本有标记。点击候选后立即记住本曲并收起面板。搜索框支持歌名、歌手与键盘搜索；查询中显示状态并暂停重复提交，空结果保留搜索入口。

“清除本曲选择，恢复自动匹配”需要再次确认；取消保留绑定，确认只清除当前歌曲的选择，不清除同步偏移和来源设置。

自动匹配、手动搜索和预载缓存只接受带时间轴的逐行／逐字歌词。旧纯文本绑定保留在本地，先尝试原来源和歌曲 ID 增强；失败或仍无时间轴时查询其他同步候选，均不可用则保留原生正文。

## 直接调整本曲同步

没设置时胶囊显示“偏移”，设置后显示 `+1s` 或 `−0.5s` 等读数。点胶囊会在原位上下露出相邻档位。向上拨增加偏移，向下拨减少偏移，也可点相邻档位或用鼠标滚轮。每格 0.5 秒，范围 ±10 秒。调节只记住本曲，不改变音频进度。

展开时相邻档位从胶囊上下滑出，点滚轮下方的回转箭头归零。松手后刻度轻轻归位，偏移数值即时生效。设置按钮保持可见，点它会收起滚轮并打开设置。点滚轮中央或歌词正文也可收起。歌词正文位置不变，切歌或离开歌词页会收起。关闭系统动画时，控件直接切换。

旧版保存的 0.1 秒等偏移不会因更新或展开控件改变；调整时才进入半秒档。

无歌曲时禁用搜索、重取和偏移；来源、译文和预载仍可设置。切歌关闭面板，旧歌曲的延迟命令不能修改新歌。

## 设置只保留偏好与维护操作

来源按真实优先顺序排列，开关控制是否参与查询，向上箭头提高优先级。关闭全部来源继续使用原生歌词。「显示译文」控制原来源译文和自动跨源补译的显示。预载准备后续三首，并显示等待队列、当前查询优先或缓存进度。“重新获取歌词 / 恢复显示”重新查询，并重置歌词渲染器已耗尽的恢复预算。所有偏好、绑定与偏移沿用原存储键。

## 离线组件与生命周期

- MDUI 2.1.5 的 Button、ButtonIcon、Switch、TextField、List 和 ListItem 固定在 lockfile，完整许可内嵌并保存在 APK `assets/third_party/SETTINGS-NOTICES.txt`。不加载宿主 AndroidX 或 Material 资源。
- 同一 Activity 内只加载一次本地页面。歌词页挂载后延迟 600ms 预热；关闭／切歌仅收起并暂停，重开不重新导航或创建 WebView。Activity 销毁或渲染故障才释放，其他 Activity 不复用旧窗口。
- 偏移滚轮锚定原生标题栏的胶囊，不参与正文布局。拨过一档有轻触反馈，支持键盘方向键和系统无障碍调节；不创建 WebView，不依赖宿主 Material 主题。`SyncExpansion` 只记录滚轮所属歌曲，偏移仍经原生端即时写入原 `OffsetStore`；切歌会取消未结束的手势。
- 归零使用 Google Material Icons 官方 `replay` 24px 素材；预览内嵌原始 SVG，原生端使用等价填充路径。原始素材与来源记录在 `demo/vendor/material-icons/`，许可与归属见第三方声明。
- `SettingsState` 传状态快照；`SettingsCommand` 限定操作类型、搜索长度、来源／候选 ID、整数偏移与歌曲身份。候选按来源 + 歌曲 ID 选择，不依赖列表下标；快速微调由原生端顺序累计。
- 外部文本使用 `textContent`；所有网络、文件与 Content Provider 访问均关闭，仅允许截获的本地主文档。页面不访问 CDN、远程字体或歌词接口。
- 设置页启动失败、10 秒超时或渲染进程退出时销毁自己的 WebView。可见时提示并打开基础设置；后台预热失败只记录，不打断听歌。歌词 WebView 的两次限次恢复策略不变。

## 背景范围

固定宿主 9.41.52 的 `vly.F` 只占标题槽；外层标题栏还包含并列的原生关闭键和上方拖动条。模块给这个外层标题栏与歌词正文使用同一封面暗色，保留圆角和原生关闭行为，不染到迷你播放器或系统导航栏。选词、设置和偏移使用标题栏已有的加权中栏，不依赖宿主标题的可见性或约束宽度；中栏没排出足够空间时保留正文内的快捷行。重新绑定时恢复原视图和布局参数，原生 F/G 动作条的直接子项数量不变。

## 电脑预览与手机验收

运行 `npm --prefix demo run build` 和 `npm --prefix demo test`。本地服务启动后打开 [完整界面预览](http://127.0.0.1:63158/settings-preview.html)，可操作实际的 MDUI 设置页；歌曲、查询及持久化由电脑内存模拟。歌词正文、标题和偏移滚轮可预览布局与交互，手机上另检查背景和触控。

手机由使用者检查：

1. 安装同签名 APK，先用「日不落 (Live)」复测。检查三枚快捷按钮和原生关闭键都可点击，拖动条、按钮区和关闭键周围的底色连贯；关闭或切到其他面板时背景恢复，迷你播放器不变。
2. 选词、搜索、空结果、选择绑定、清除确认与取消；长歌名、歌手和专辑可区分，没有旧式候选弹框。
3. 点偏移胶囊，确认正负读数保持在原位，滚轮档位向上下展开，正文和原生关闭按钮不移动。上下拨动、点相邻档位和归零。滚轮展开时直接点设置，确认滚轮收起且设置打开。退出再进，只显示保留的本曲偏移。
4. 在选词／设置之间切换，检查大面板顶部保持同高；反复关闭／打开，检查已预热页面的响应；切换来源、上移、译文与预载，确认即时保存，音频不中断。
