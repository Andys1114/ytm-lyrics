# 隐私与数据流

## 查询发送什么

仅请求已启用的歌词来源。自动查询发送当前歌曲的歌名、歌手、可选专辑与时长；人工搜索发送输入的关键词，再使用来源歌曲 ID 取词。来源各自可见收到的查询与网络连接信息。

默认启用播放队列预载，最多滚动查询接下来三首的必要匹配信息；可在歌词设置关闭。预载不读取歌单账号、Cookie 或登录凭据。

LRCLIB 使用公开接口；QQ／网易云使用未公开接口。协议实现分别见 `app/source`，来源开关不会删除已有缓存或手动绑定，但禁用来源后不会继续使用其绑定进行显示。

## 什么留在本机

绑定、来源配置和译文开关保存在 YTM 私有 SharedPreferences；本曲偏移与自动预载缓存分别保存。自动缓存有效期 24 小时，最多 30 首、候选 JSON 总量最多 4MiB。清除 YTM 数据会删除这些内容；模块不提供云同步或遥测。

封面直接读取 YTM 已有媒体会话位图，缩图后只在内存中用于背景，不写入歌词缓存，不向外部传输。WebView 仅加载 APK 自带页面，禁止网络、文件及 content URI 访问，只接受本地 data 图片。

译文使用所选来源返回的数据，不调用机器翻译，也不跨来源拼接。来源歌词及专辑图片的权利仍属于各自权利人。

## 日志与反馈

模块的框架／Logcat 记录可能包含版本、错误、歌曲查询相关内容或异常信息。公开反馈前只保留有关片段，删除个人信息、账号、Cookie、设备标识和无关通知；不要发布完整歌词或原始设备导出。

仓库排除本机 `.analysis`、`.device`、`.tooling`、签名、宿主安装包与构建产物。提交前仍应人工检查暂存清单；`.gitignore` 不能让已提交过的秘密自动消失。
