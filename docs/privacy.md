# 隐私与数据流规范

YTM Lyrics 遵循最小数据暴露原则，本文件详述插件的网络请求、本地存储结构、沙箱安全隔离与日志脱敏规范。

## 网络请求与外部通信

插件仅在用户启用相应功能并播放歌曲时，向已勾选的歌词来源发起 HTTP(S) 请求。不包含任何第三方追踪、统计分析或远程遥测代码。

### 请求清单

| 来源 | 请求类型 | 目标接口 | 传输的数据 | 是否含账号/凭据 |
| --- | --- | --- | --- | --- |
| **网易云音乐** | 未公开接口 | 移动端搜索与 YRC / 译文接口 | 歌名、歌手、来源内部数字歌曲 ID | **否**（无 Cookie、无登录） |
| **QQ 音乐** | 未公开接口 | 搜索接口与 QRC 歌词接口 | 歌名、歌手、来源内部 `musicid` / `songid` | **否**（无 Cookie、无登录） |
| **LRCLIB** | 公开 API | `https://lrclib.net/api/get` / `search` | 歌名、歌手、可选专辑名、音频时长 | **否**（完全匿名） |

> [!IMPORTANT]
> - **来源限制**：关闭某个来源后，插件将彻底停止向该来源发送任何新请求。
> - **队列预载**：后台预载机制仅对接下来 3 首待播歌曲发送歌名与歌手以获取候选，**绝对不读取、上传或访问用户的 YouTube Music 账号、Cookie 或私人歌单信息**。

## 本地数据存储与隔离

所有用户配置、缓存与绑定数据均保存在 YouTube Music 应用的私有数据目录中，外界应用无法读取。

### 存储分区结构

| 存储分区 | 保存内容 | 生命周期 / 容量限制 | 清除方式 |
| --- | --- | --- | --- |
| 偏好与手动绑定 | 来源启停开关、来源排序、译文开关、用户**手动绑定的歌词映射与缓存** | 永久保存（除非用户手动重新绑定） | 清除 YTM 应用数据 |
| 单曲偏移 | **本曲同步时间偏移**（每首歌曲的 `Song.key()` 对应毫秒数值） | 永久保存，切歌自动保存 | 清除 YTM 应用数据 |
| 自动候选缓存 | **播放队列自动预载候选池**与当前歌曲临时缓存 | **24 小时过期**；最多存储 **30 首**；JSON 数据总量上限 **4 MiB**，超限自动淘汰最旧记录 | 超限自动淘汰，或清除应用数据 |

> [!NOTE]
> 手动绑定的歌词与自动预载缓存使用独立的存储键空间。自动预载的容量淘汰**绝不会**删除或篡改用户手动绑定的歌词。

## 媒体封面与本地 WebView 沙箱

1. **封面数据不出设备**：
   - 封面直接读取宿主现有 `MediaSession` 已缓存的位图。
   - 在本地工作线程压缩至最长边 256px，以 JPEG Base64 形式仅传递给内存中的本地渲染页面。
   - **不向任何外部服务器发送专辑封面，也不将封面位图写入磁盘缓存**。
2. **WebView 安全沙箱**：
   - 页面加载自内部拦截虚拟地址（`https://ytm-lyrics.invalid/lyrics.html`），不开放通用 Web 浏览。
   - 内容安全策略（CSP）严格锁定：
     ```http
     default-src 'none'; img-src data:; style-src 'unsafe-inline'; script-src 'unsafe-inline'; connect-src 'none';
     ```
   - **完全禁用网络连接（`connect-src 'none'`）**：WebView 内部的 JavaScript 无法发起任何 `fetch`、`XMLHttpRequest` 或 WebSocket 请求。
   - **完全禁用外部资源访问**：禁止访问 `file://`、`content://` 协议，杜绝本地文件泄露风险。

## 日志脱敏与公开交流指引

当你在 GitHub Issue、社区讨论或向开发者反馈问题时，若需要提供系统 Logcat 日志或截图，请遵循以下规范：

- [ ] **日志脱敏**：检查日志片段，删除任何包含个人设备标识（IMEI/Android ID/序列号）、Google 账号邮箱、WiFi/IP 地址、蓝牙设备名称及无关应用通知的内容。
- [ ] **截图保护**：截图时裁切或打码顶部状态栏（通知、电量、运营商）与个人头像。
- [ ] **歌词与版权保护**：请勿在 Issue 或 PR 中批量分发完整的真实版权歌词文本；报告问题时仅提供最小复现样例或自写测试词句。
- [ ] **严禁上传私钥与 APK**：严禁在公开仓库提交 `.tooling/` 目录中的维护者签名密钥、YTM 官方 APK 安装包或反编译源文件。
